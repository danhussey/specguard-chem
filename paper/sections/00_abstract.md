# Abstract

Scientific language agents are increasingly evaluated on tasks that mix natural-language instructions, structured constraints, tool use, and decisions to accept, reject, or abstain. In formalizable domains, such evaluations can overstate capability when they conflate prompt following, leakage, action-set ambiguity, and deterministic verifier access. We introduce SpecGuard-Chem, an oracle-compiled evaluation contract and audit harness for chemically typed specification compliance.

SpecGuard-Chem emits bundle-stable train/dev/test splits, public task views, hidden oracle certificates, action-constrained outputs, and audit artifacts for construction, repair, candidate audit, rejection, abstention, verifier-tool use, boundary precision, representation invariance, and interrupt/resume behavior. The sgchem_v1.0 release contains 118 bundles and 656 tasks, including 266 held-out test tasks, with strict validation, leakage audits, oracle scrambling, negative controls, clean-clone reproduction, and Croissant metadata.

Empirically, we show that molecule acceptance alone is misleading: deterministic and retrieval baselines often produce or select passing molecules while failing rejection and abstention semantics, yielding action accuracy near the majority-action baseline and high task-inconsistent acceptance. A deterministic engineered verifier/search wrapper saturates the full test split under the public verifier/search-wrapper threat model.

We use this saturation result to argue that formalizable scientific-agent benchmarks should publish oracle contracts, public/private isolation audits, metric denominators, and verifier-wrapper baselines before making capability claims. SpecGuard-Chem is not a drug-discovery benchmark; it evaluates specification-compliance contracts, not biological activity, toxicity, synthesizability, clinical utility, or therapeutic value.

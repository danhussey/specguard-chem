# Conclusion

SpecGuard-Chem sgchem_v1.0 provides a validated oracle-first artifact for evaluating specification compliance under medicinal-chemistry constraints. Its main contribution is not only the task set, but the compiler and audit harness: bundle-aware splitting, hidden-oracle isolation, deterministic validation, negative controls, prompt leakage audits, oracle scrambling, and action-aware metrics.

The release supports defensible reporting of construction, repair, audit, rejection, abstention, tool use, boundary, invariance, and interrupt/resume behavior. The paper should emphasize that molecule_acceptance_rate alone is insufficient and that action-aware evaluation reveals unsafe acceptance and failure to reject or abstain.

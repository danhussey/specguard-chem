# Introduction

Language-model agents are increasingly asked to follow structured scientific specifications, interact with tools, and make accept/reject/abstain decisions. A defensible evaluation needs to separate visible instructions from hidden answers, prevent leakage across related examples, and report metrics that distinguish successful construction from task-inconsistent acceptance or failure to abstain.

SpecGuard-Chem uses medicinal-chemistry specifications as a scoped, chemically typed domain for this evaluation problem. The specifications use molecular property ranges, substructure constraints, alert filters, similarity guards, and representation-equivalence checks. This domain is useful because it supports deterministic local verification while still exercising realistic specification-following, tool-use, rejection, and abstention behavior.

The benchmark is not a molecule-discovery claim and should not be interpreted as an intrinsic chemistry-capability leaderboard. SpecGuard-Chem does not evaluate biological activity, toxicity, synthesis feasibility, therapeutic efficacy, clinical utility, target binding, dosing, disease relevance, or drug-discovery success. The scientific object of study is evaluation design: oracle-backed task compilation, public/private task isolation, validation gates, action-aware reporting, and verifier-wrapper saturation.

We make three contributions. First, we introduce SpecGuard-Chem, an oracle-first compiler that generates chemically typed, machine-checkable public task views with hidden witnesses and certificates. Second, we release sgchem_v1.0, a validated 656-task artifact covering construction, repair, audit, rejection, abstention, verifier-tool use, boundary precision, representation invariance, and interrupt/resume behavior. Third, we report a verifier-wrapper saturation study: a deterministic engineered wrapper solves the test split, showing that this evaluation is best interpreted as a specification-compliance contract rather than a raw model capability leaderboard.

The sgchem_v1.0 release has 118 bundles, 656 tasks, and 266 test tasks. The paper-facing claim ledger is `paper_v1/claim_ledger.yaml`, and every empirical claim is tied to a denominator table, audit report, or reality-check memo.
